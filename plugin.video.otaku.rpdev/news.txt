                    OTAKU RPDEV v5.7.0 - WHAT'S NEW & MILESTONES
================================================================================

[ Kodi 22 (Piers RC) Ready • Universal Backwards Compatibility • Milestone v5.7.0 ]

Welcome to Otaku RPDev v5.7.0! This milestone release introduces advanced playback
and architecture modernizations inspired by Umbrella: zero-wait direct stream pre-
resolution, an interactive "Still Watching?" binge safeguard, concurrency-safe request
coalescing, provider-specific color palette branding, and an orphaned settings pruner.

--------------------------------------------------------------------------------
New in v5.7.0: Umbrella Architectural Adoptions & Playback Modernization
--------------------------------------------------------------------------------
• Zero-Wait Pre-Resolved Stream Handoff: During episode playback at 70% progress,
  Otaku pre-scrapes the next episode and silently resolves the direct stream URL in the
  background (resolve_silent). When the current episode finishes, playback of the next
  episode starts instantly with 0 ms resolver lag and no dialog popups.
• "Still Watching?" Binge Safeguard: Interactive StillWatchingXML countdown prompt
  triggers after consecutive autoplayed episodes (default: 3 episodes, 30s timeout).
  If unattended, it clears the playlist and pauses playback, protecting Debrid quotas
  and preventing false watch history updates on AniList/MAL.
• Concurrency-Safe Request Coalescing (get_coalesced): Eliminates SQLite database lock
  collisions and redundant remote API requests when multiple Python invokers execute
  simultaneously using micro-coordination SQLite locking with BEGIN IMMEDIATE.
• Provider-Specific Color Palette Branding: Source selection lists now display vibrant
  brand colors for each Debrid provider (Premiumize Purple, Real-Debrid Blue, TorBox
  Orange, AllDebrid Green) and web embed sources for effortless scanning.
• Orphaned Settings Pruner (clean_settings): Automatically sanitizes userdata
  settings.xml upon version upgrades and provides a manual action button under
  Settings -> Cache & Database to remove deprecated tags and eliminate Kodi 22 C++ warnings.

Major Highlights & Upgrades in v5.6.0
--------------------------------------------------------------------------------

1. Zero-Wait Fast-Path Background Pre-Caching
   • Background pre-scraping at 70% playback progress now persists whole-episode
     sorted sources with a 4-hour TTL directly into SQLite database cache.
   • When starting the next episode (or auto-playing via SmartPlay), MetaBrowser
     uses Fast-Path 2 to return the pre-cached stream immediately in 0.001s.
   • Completely eliminates the scraping dialog (get_sources.xml) and stops
     45-second UI freezes caused by unresponsive or failing scrapers.

2. SmartPlay Web Embed Continuity (smartplay.prefer_same_embed)
   • Hands-free binge watching on web embed providers (Anikoto/MegaPlay,
     AnimePahe, HiAnime, etc.)!
   • When you select an embed source for Episode 1, SmartPlay preserves your
     chosen provider and audio language (Sub vs. Dub) across subsequent episodes.
   • resolver.reorder_sources and pages.sortSources prioritize the matching
     provider at index 0 and hand off directly to playback without prompting.

3. Kodi 22 (Piers RC) Strict Settings Typing & Zero C++ Exceptions
   • Kodi 22 strictly enforces declared setting types, throwing fatal C++
     exceptions if an add-on touches an undeclared setting.
   • All internal settings (dub.etag, mappings.etag, mappings.last_modified,
     verify_ssl, last_played_source, last_watched_series, prefer_same_embed)
     are now formally registered and typed in resources/settings.xml.
   • Zero C++ setting exceptions across Kodi 20, Kodi 21, and Kodi 22 RC!

4. SWIG Director Memory Leak Elimination
   • Addressed Python invoker C++ SWIG wrapper leaks during playback transitions.
   • WindowXMLDialog instances (SourceSelect, Resolver, SkipIntro, PlayingNext)
     are explicitly tracked, closed, and unbound to prevent SwigDirector warnings
     and memory accumulation during extended viewing sessions.

5. Anikoto Scraper Hardening
   • Fixed an issue where Anikoto aborted early if show records were not yet
     indexed in the database.
   • Added multi-tier fallbacks (shows_meta, episodes, synthetic IDs) so the
     MegaPlay API endpoint is always queried.
   • Scraper diagnostics elevated to info level for transparent troubleshooting.

6. Upcoming Dub Release Date Badges (v5.5.20)
   • For anime with upcoming dub releases, the exact dub broadcast date is
     displayed right-aligned in the episode row (Label2) next to the watch icon.
   • AnimeSchedule scraper parses ISO timezones and converts to your local time.

7. Auto-Skip Chapter Resolution & Heuristics (v5.5.19)
   • Evaluates embedded MKV/MP4 chapters with OP/ED confidence detection and a
     90-second duration heuristic, preventing false skips during story prologues.

8. Debrid Cache Availability Integrity (v5.5.21)
   • Prevents false-negative cache poisoning by storing only confirmed positive
     hashes in SQLite debrid_cache and generating fresh DMM request secrets.

9. Multi-Option Cache & Maintenance System (v5.5.1)
   • Context Menu "Clear Addon Cache" launches an interactive modal window.
   • Selective Provider Cache clearing flushes torrents, embeds, season packs,
     and debrid hashes without touching your watchlist or show metadata.

10. 252 Automated CI Tests Harness (100% Error Catching)
   • Comprehensive automated test suite in CI testing every subsystem: mock Kodi
     environment, debrid resolvers, scrapers, indexers, windows, and lifecycles.
