Major Highlights & Architectural Upgrades Since Upstream v5.4.3:
--------------------------------------------------------------------------------

1. Multi-Option Cache & Maintenance System (v5.5.1)
   • Context Menu "Clear Addon Cache" now opens an interactive modal window.
   • Defaults to "Provider Cache": instantly clears torrent scrapes, embed links,
     season packs, and debrid hashes without wiping your watchlist or metadata.
   • "All Cache & Database" option provides a full nuclear purge when needed.
   • Real-time descriptions update on navigation; dedicated Cancel button.

2. Comprehensive Test Harness & 100% Error Catching (v5.5.0)
   • 168 automated tests covering all 9 architectural phases in CI.
   • Full Kodi mock harness simulating players, lists, dialogs, and plugins.
   • Typed error guards and circuit breakers on all external API requests,
     scrapers, watchlist sync endpoints, and cloud storage providers.

3. In-Process Megacloud & Rabbitstream Decryption (v5.4.6)
   • Pure Python in-process AES-CBC / key-derivation engine for video hosters.
   • Zero external Node.js, wasm, or external worker dependencies.

4. Multi-Debrid Failover & Cloud VFS Management (v5.4.4 - v5.4.11)
   • Instant failover across Real-Debrid, AllDebrid, TorBox, and Premiumize.
   • Full Debrid Cloud VFS browser: stream, organize, rename, and manage cloud
     files and torrent downloads directly from your couch.
   • Elimination of the 5MB download cap on remote debrid media files.

5. Subtitle Intelligence & Dub Pairing (v5.4.9 - v5.4.12)
   • Intelligent distinction between full dialogue subtitles and signs/songs.
   • Automated .ass / .ssa stream header inspection and preferred audio sync.

6. Concurrency, Cancellation & Scraper Circuit Breakers (v5.4.7 - v5.4.14)
   • Bounded worker threadpools preventing UI lockups on low-spec hardware.
   • Cooperative cancellation tokens (self.canceled) terminating background
     scrapes the instant a user presses Back or selects a source.
   • Scraper circuit breaker: automatically pauses failing providers to prevent
     infinite retry storms and sluggish scraping.

7. Database & Memory Hardening (v5.4.7 - v5.4.13)
   • Complete removal of unsafe Python pickle storage in favor of SQLite + JSON.
   • SQLite WAL checkpointing, atomic file persistence, and automatic memory
     trimming (malloc_trim) on video playback end.
   • Unicode NFKD transliteration for robust Japanese romaji and title matching.

8. Living-Room UI Polish & Instant Refresh (v5.4.15 - v5.4.16)
   • Instant main menu refresh upon saving menu customization (no restarts).
   • AnimeSchedule Bearer authentication for reliable broadcast scheduling.
   • Non-blocking changelog presentations and zero C++ skin exceptions.

9. Comprehensive Context Menu Suite (context.otaku.rpdev v1.0.40)
   • "Clear Addon Cache": Now launches the multi-option modal window.
   • "Mark Episodes Up To Here as Watched": One-click bulk progress sync for
     seasons, marking all prior episodes as watched locally and on remote
     watchlists (AniList, MAL, Kitsu, Simkl).
   • Normalized Movie & Episode Watched Routing: Robust URL target extraction
     without IndexError across all play formats (play_movie, play_oot, play_al).
   • Safe Metadata Forwarding: Rescrape and Source Select preserve full video
     info tags, artwork, and resume timestamps.
   • Deep Discovery: Instant access to Find Recommendations, Find Relations,
     Get Watch Order, Anime Statistics, Fanart Selection, and Database Deletion.
